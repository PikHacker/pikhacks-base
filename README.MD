PikHacker here, I'm using this repository to make my own version of Pikmin 2 to use as a base for my many different Pikmin 2 mods.

I'll probably just focus on older simpler ones for now.
I plan to leave this as open source for transparency (something we certainly need in the current environment), but it's a personal
project for me, so I probably wouldn't use it over the 100% complete Pikmin 2 decomp proper for your own purposes, at least not for a while.

Keep in mind that I've heavily trimmed both the game itself and the actual dtk tools down to just what I need, so it will be missing
some features compared to the actual decomp, such as building other versions besides the USA version and make.

Don't really have much more to say for now, thanks for checking this out!
